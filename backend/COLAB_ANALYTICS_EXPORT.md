The Model Laboratory uses **precomputed, compact** research outputs already saved by your notebook. No model retraining is necessary.

## 1. Apply the update to VS Code

Extract `aeroscope-analytics-api-update.zip` into the **project root**, where `backend/` and `.gitignore` are visible. Replace files when prompted. This update adds analytics endpoints and adds an ignore rule for `backend/data/analytics/`.

## 2. Export research summaries from Google Colab

Run this **single new cell** in your original notebook (after mounting Drive). It reads the results generated by Chunks 19A, 20C, 21A, 22E and 23E.

```python
from pathlib import Path
from zipfile import ZipFile, ZIP_DEFLATED
from google.colab import files
import pandas as pd
import joblib
import json

root = Path('/content/gdrive/MyDrive/INSAT3D_AOD_Project/enhanced')
results = root / 'outputs' / 'results'
features = root / 'data' / 'features'
models = root / 'models'

names = [
    'enhanced_kmeans_evaluation.csv',
    'final_model_a_profiles.csv',
    'final_model_b_profiles.csv',
    'alternative_clustering_comparison.csv',
    'final_robustness_summary.csv',
]
for name in names:
    if not (results / name).is_file():
        raise FileNotFoundError(f'Missing saved result: {results / name}')

pca_summary = {}
for model in ('model_a', 'model_b'):
    # Load only your own trusted Colab-generated joblib artifacts.
    pca_path = models / f'{model}_pca.joblib'
    coords_path = features / f'final_{model}_clusters.csv'
    if not pca_path.is_file() or not coords_path.is_file():
        raise FileNotFoundError(f'Missing PCA model or saved coordinates for {model}')
    pca = joblib.load(pca_path)
    frame = pd.read_csv(coords_path, usecols=['cluster_id', 'PC1', 'PC2'])
    stats = (
        frame.groupby('cluster_id', as_index=False)
             .agg(cells=('cluster_id','size'), PC1=('PC1','mean'), PC2=('PC2','mean'))
             .sort_values('cluster_id')
    )
    pca_summary[model] = {
        'explained_variance_ratio': [float(x) for x in pca.explained_variance_ratio_],
        'total_explained_variance': float(pca.explained_variance_ratio_.sum()),
        'centroids': [
            {'cluster_id': int(r.cluster_id), 'cells': int(r.cells),
             'PC1': float(r.PC1), 'PC2': float(r.PC2)}
            for r in stats.itertuples(index=False)
        ],
    }

archive_path = '/content/aeroscope_analytics.zip'
with ZipFile(archive_path, 'w', ZIP_DEFLATED) as archive:
    for name in names:
        archive.write(results / name, arcname=f'aeroscope_analytics/{name}')
    archive.writestr('aeroscope_analytics/pca_cluster_summary.json',
                     json.dumps(pca_summary, indent=2, allow_nan=False))

print('Model Laboratory export complete:', archive_path)
files.download(archive_path)
```

The PCA export contains **cluster centroids only**, not individual grid-cell coordinates or the full PCA scatterplot. These saved outputs are historical research summaries, not real-time pollution measurements.

## 3. Import model summaries into Flask (Windows PowerShell)

From `backend/` with `.venv` active:

```powershell
python -m scripts.import_analytics "$HOME\Downloads\aeroscope_analytics.zip"
python -m pytest -v
flask --app wsgi run --debug
```

If updating an older analytics export, use `--overwrite`. The importer does **not** update your existing Parquet, GeoTIFF, hotspot files or trained ML models.

## 4. Open API endpoints

- `/api/v1/models/analytics-status` (which outputs are installed)
- `/api/v1/models/model_a/metrics` (K=2–8 evaluation rows)
- `/api/v1/models/model_a/profiles` (final cluster profiles)
- `/api/v1/models/model_a/comparisons` (K-Means, GMM, Manhattan K-Medians)
- `/api/v1/models/model_a/robustness` (seed/feature/subsample robustness)
- `/api/v1/models/model_a/pca` (PCA cluster centroid summary)

Replace `model_a` with `model_b` to inspect seasonal aerosol clustering. These routes produce JSON for chart components; they do not render charts themselves.

## 5. Public-data safeguard

The `data/analytics/` directory is `.gitignore`d. Do not commit the export ZIP or push the summary files to a public host until MOSDAC's rules and any applicable access conditions have been reviewed.

When `AEROSCOPE_ENV=production` and `AEROSCOPE_PUBLIC_RESULTS_ENABLED=false`, these analytical result endpoints return HTTP 403. The status endpoint is still available without disclosing measurements. Historical AOD is **not** ground-level PM2.5, real-time AQI or causal source attribution.

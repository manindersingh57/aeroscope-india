# AeroScope India: Evaluation & PCA cleanup

This is a frontend-only update for the existing `claude-redesign` branch.

- Removes the **Import Colab CSV** button, hidden input, CSV parser, local-report state and fallback hint from ML Laboratory → Evaluation curves.
- Preserves **Selected model**, **Compare A+B**, all four scientific metrics, and automatic use of the existing Flask research API.
- Renames the nearby ML Laboratory PCA panel **PCA · cluster centroids**, clarifying that it shows just the centers of the groups, not individual data points. The `PC1 + PC2 explained variance` figure comes from the PCA fit to the underlying feature data, not just the plotted centers.
- Full PCA scatter plots belong in **Cluster Insights**, where the existing local-only Flask PCA scatter endpoint displays actual PC1/PC2 points if both CSV exports are installed privately.
- Does not change your ML models or backend endpoints. Does not embed research data.

## Install (Windows PowerShell)

In project root, back up or commit any current changes first and confirm the `claude-redesign` branch:

```powershell
git branch --show-current
git status
Expand-Archive -Path "$HOME\Downloads\aeroscope-evaluation-pca-cleanup.zip" -DestinationPath . -Force
python tools\apply_evaluation_pca_cleanup.py
cd frontend
npm run build
npm run dev
```

Go to `http://localhost:5173/models`. The curves load only if local Flask has verified saved evaluation data and the frontend points to its API URL. Restricted public deployments show the unavailable-data state.

## PCA interpretation

Four dots for Model A K=4, or five dots for Model B K=5, are correct for *centroid projection*. The positions summarize between-center separation but cannot show within-cluster spread, overlap or outliers. `98.4%` means PC1+PC2 jointly explain 98.4% of the original feature variance if that number is generated by your fitted PCA; it is not accuracy or goodness-of-clustering. The notebook's Chunk 21A computes PCA separately in each model feature space with `PCA(n_components=2)` fitted to the full feature array. Verify the current Flask `pca_cluster_summary.json` export was calculated from the same saved experiment.
